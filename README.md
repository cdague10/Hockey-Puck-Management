# Hockey-Puck-Management
Using tracking data, I created a rating system to evaluate how individual players handle the puck. Their efficiency rating is dependent of event type, location, and the player's position. Every position has a different weight value of features, based on position. *Data is accurate but teams and names are replacing the actual players.* The only data missing is the player tracking data. Ratings such as pass eff, zone control, dump in and recovery success, puck management while contested/uncontested and location-specific values for every event that occurs.
